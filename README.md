# Loading Screen Gold: A Tip in 200 Characters

A single loading-screen tip for stressed developers and the AI coding agents working beside them — the loading bar isn't stuck, you and your agent are just both waiting for the other one to admit nobody understands this code.

## The tip

> Tip: the loading bar is not stuck. You and your agent are both waiting for the other one to admit nobody understands this code.

## How to run

```sh
node main.ts
```

This writes the tip as a single line to `entry.txt` in the output directory (`/output` by default, or `$OUTPUT_DIR` when set). The program validates the tip first — 1–200 characters counted by code points, exactly one line, no control characters, no leading or trailing whitespace — then reads the file back and fails loudly if the round-trip differs.
